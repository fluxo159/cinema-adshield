# Проверка перед публикацией

Дата: 17 ноября 2026. Это проверка исходников и состава публикации, не сторонний пентест и не гарантия отсутствия всех уязвимостей.

## Общие проверки

- Gitleaks 8.30.1 с проверкой SHA-256 сканера: подготовленные файлы без находок секретов. Перед отправкой также сканируется вся новая Git-история.
- Проверены имена файлов и личные идентификаторы; рабочие .env, базы, cookies, журналы, локальные карточки и готовые старые приложения исключены.
- Git-автор использует GitHub noreply, а не личную почту.
- CI имеет только `contents: read`; Actions закреплены полными SHA, секреты сервера не используются.

## CinemaAdShield

- Убраны `<all_urls>` и неиспользуемые scripting/activeTab/feedback-разрешения.
- Некорректные wildcard-TLD заменены явным списком HTTPS-доменов; зеркала вне списка автоматически не получают доступ.
- Runtime-команды ограничены своим расширением; сброс статистики доступен только popup, инкремент счётчика ограничен.
- Native Swift-обработчик не логирует и не возвращает произвольные сообщения браузера.
- Убраны локальные идентификаторы Signing Team; установленные приложения, сборки и Xcode-userdata исключены из Git.
- 4 теста границ сообщений, manifest и согласованности Safari/Chromium-копий пройдены; синтаксис JavaScript проверен.

Полного Xcode на машине нет: компиляция/подпись Safari-приложения и живой прогон сайтов в этой проверке не выполнены. Старый готовый .app не обновлён и не публикуется. Userscript сохранён отдельно; его широкие правила не являются разрешениями Web Extension. Не включайте его без проверки выбранных сайтов. Полная блокировка рекламы не гарантируется.
