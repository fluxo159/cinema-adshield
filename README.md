# CinemaAdShield

**Safari Web Extension для блокировки рекламных запросов и отвлекающих элементов на поддерживаемых видеосайтах.** Исходники расширения и оболочки для macOS.

## Что есть

- Декларативные правила блокировки сетевых рекламных запросов.
- Обработка баннеров, всплывающих окон и отдельных элементов плеера.
- Переключатель, список исключений и локальные счётчики.
- Swift-оболочка Safari Web Extension и отдельный userscript.

## Структура

| Папка | Содержимое |
|---|---|
| `extension/` | JavaScript, popup, правила и Manifest V3 |
| `CinemaAdShield/` | Xcode-проект и встроенная копия расширения |
| `CinemaAdShield.user.js` | Самостоятельная userscript-версия |
| `scripts/` | Подготовка иконок |

## Сборка

Для Safari нужны macOS и полный Xcode. Откройте `CinemaAdShield/CinemaAdShield.xcodeproj`, выберите собственную Signing Team и соберите приложение. Запустите собранную оболочку и включите расширение в настройках Safari, предоставив доступ только к нужным сайтам.

Для Chromium загрузите `extension/` через режим разработчика. Поддерживаемые домены явно перечислены в `manifest.json`; зеркала с другим адресом требуют осознанного изменения списка. Для установки исходников недостаточно старого готового `.app`: он не включён в репозиторий.

## Приватность и ограничения

Счётчики и список исключений остаются в локальном хранилище браузера. Телеметрии и сервера приложения нет. Идентификаторы подписи Apple и данные личной установки исключены.

Сайты и плееры меняются; полная блокировка рекламы, работа всех зеркал и текущая совместимость с YouTube не гарантируются. Userscript — отдельный механизм с собственными разрешениями; его не следует включать одновременно с расширением без необходимости.

```sh
node --test tests/*.test.cjs
```
